# Real-estate-website
A responsive and user-friendly Real Estate Website developed using HTML, CSS, and JavaScript. This project showcases property listings with a modern UI and smooth user interactions, making it easy for users to explore, search, and view property details.
🔹 Features

Responsive design for mobile, tablet, and desktop

Property listing cards with images and details

Search and filter properties based on user input

Interactive UI using JavaScript

Clean and modern layout using CSS

Smooth navigation and user experience

🔹 Technologies Used

HTML5 – Structure of the website

CSS3 – Styling and responsive layout

JavaScript – Dynamic functionality and interactivity

🔹 Purpose

This project is created to demonstrate frontend development skills and understanding of real-world web applications like property listing platforms. It is suitable for beginners and showcases practical implementation of core web technologies.
